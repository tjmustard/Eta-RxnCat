A": geometry optimization sits behind an `Optimizer` interface (`eta_rxncat.optimize`). geomeTRIC 1.1.1 is one implementation, `GeometricOptimizer`, shipped in the optional extra `opt-geometric = ["geometric==1.1.1"]` and also in the dev dependency group so the default test suite exercises it (mission R5). It leaves `[project].dependencies`; the base runtime closure loses geometric, networkx and six (R14). The licence-gate exemption (BSD 3-clause Non-AI, ADR-0011) follows the package: removed from `base`, pinned in a new `opt-geometric` profile, kept in `gpu`/`mlip-mace`/`mlip-uma` because `gpu4pyscf-cuda12x` pulls geomeTRIC in when CI syncs those profiles with `--extra gpu`. This amends ADR-0011's "required dependency" scope; the exemption's terms are unchanged. Source: missions/release-0.3.0 R5, R14, R38; slice 04.
