Atom maps between a graft and a reference structure are derived by a stated rule that uses no coordinates: perceive connectivity (RDKit DetermineConnectivity, defaults) of the reference and build the graft's source graph from the template and fragment graphs plus junction bonds; enumerate element-preserving isomorphisms; take the lexicographically smallest map tuple. Never choose a map by minimising an RMSD that a fixture gates. The isomorphism count and the gated RMSD under each distinct heavy-atom map are reported so the human reviewer sees the choice was not tuned; TJ confirms the map by promoting the candidate that carries it.
