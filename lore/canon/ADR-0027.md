TJ R1 "R1. A": candidate outputs are committed on the feature branch. To keep the agent firewall meaningful, each E2E slice commits code first (C1, clean tree), runs the E2E tests at C1 so every candidate records `commit_sha = C1`, then commits only `tests/candidate_outputs/<version>/*` as C2 ("candidates produced at C1"). Every `git diff`, `git show` and `git log -p` by any seat over a range containing C2 uses the pathspec `-- . ':(exclude)tests/candidate_outputs'`; C2 is checked by file names only. Committing a candidate is not promoting it; only TJ promotes into `tests/fixtures/`. Acceptance is split around TJ's Phase 3 gate: a record slice whose PASS needs no human action, then the gate, then a verdict slice under `ETA_RXNCAT_ACCEPTANCE=1` on a fresh store. Source: missions/release-0.3.0 R4, R22, R23; slices 07–10.
