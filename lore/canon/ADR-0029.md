Alignment in eta_rxncat.mapping is Horn's 1987 unit-quaternion superposition (largest eigenvector of the 4x4 key matrix via numpy.linalg.eigh): a proper rotation by construction, no reflection fix-up, RMSD from residual coordinates. Degenerate pair sets are refused with AlignmentError: fewer than 3 pairs, an RMS off-line deviation (sqrt((s2^2+s3^2)/k) of the centred set) <= 1e-3 A on either side, or a top-eigenvalue gap <= 1e-10*max(1,|lambda1|). Planarity (s3/sqrt(k)) is reported, and a planar pair set is flagged (<= 0.05 A), because a planar set's reversed sense is reachable by a proper rotation (clean-room nMAP spec §4.3). thermo's SVD Kabsch is not reused or touched; tests cross-check against an independent residual-based SVD written in the test (agreement measured <= 4.4e-15 A). Source: missions/release-0.4.0 R5, R12, R16, R19.
