Decision (resolve, v0.1.0, R7/R25; Red Team F7, F25). Status enum pending/running/completed/failed. A completed row is changed only by invalidate(); an identical completed re-put is a no-op; any other write raises ArtifactConflictError. PRAGMA user_version = 1 (other values refused), journal_mode=WAL, busy_timeout=5000. No default path; the parent directory must exist; nothing else is created. Payloads are canonical JSON TEXT with payload_sha256; sidecar blobs are deferred to the first version that stores Hessians. Why: crash-safe resume depends on never losing a completed artifact.
