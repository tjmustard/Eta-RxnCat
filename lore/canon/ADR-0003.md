Decision (resolve, v0.1.0, R9/R23; Red Team F9, F23). All core models use extra=forbid and frozen=True. charge, spin_multiplicity, counts, ranks, priorities and indices are StrictInt (bool, str, float rejected). Element symbols must be canonical Z 1-118. Electron parity: n_e = sum(Z) - charge >= 0, mult-1 <= n_e, (n_e - (mult-1)) even. Coordinates finite. YAML loads through a SafeLoader subclass that rejects duplicate keys; JSON through an object_pairs_hook that does the same. ThermoConfig standard_state_mol_l defaults to 1.0 and can never be None; qRRHO alpha (4.0) and rotor moment (1e-44 kg m^2) are fields. Why: the plan's core promise is that charge and spin are never silently wrong.
