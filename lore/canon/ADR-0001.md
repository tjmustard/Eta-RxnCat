Decision (resolve, v0.1.0, R5/R6/R22; Red Team F5, F6, F22). The stage cache key is sha256 of canonical JSON {key_schema: 1, geometry_hash, stage_hash}. Geometry: symbols, coordinates rounded to 5 decimals with -0.0 normalised and written as fixed-point strings, charge, multiplicity, sorted active atoms. Stage: kind, engine tag, method, basis, solvation, sorted frozen atoms, options (integral floats as ints) and a required EngineIdentity (name, version, model). Metadata is not keyed. Engine tags frozen to the plan's names: rdkit_ff, mace, uma_direct, pyscf_gpu_cpu, xtb_subprocess. A key_schema bump makes old keys miss; keys are never migrated. Why: a wrong cache hit is a silent scientific error; whole-model dumps change with every added field. Mission: missions/release-0.1.0/SPEC.md §5.
