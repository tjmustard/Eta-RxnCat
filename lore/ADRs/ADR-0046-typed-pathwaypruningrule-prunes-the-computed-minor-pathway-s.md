Context: TJ Q2 "A: evaluated per-pathway rule in core + optional pathway labels + small selectivity runner; 1.5 in the Tier 4 fixture, no library default (the recommendation)." Red team F7 found the draft's semantics ambiguous (static pair vs computed minor, unsigned vs signed ΔΔG‡, empty pathways, unlabelled nodes).
Decision (mission release-0.6.0 R7, R23): a typed PathwayPruningRule(id, metric "ddG_dagger_kcal_mol", pathways (a, b), threshold_kcal_mol required > 0, prune "minor_pathway_priority_ge_2") lives in ReactionGraph.pathway_pruning_rules beside the inert free-form PruningRule, which is unchanged. It is evaluated once after both pathways have ensembles: iff ΔΔG‡ > threshold (strict), the computed minor pathway's nodes with priority ≥ 2 and pathway == minor are pruned (status pruned, no engine call). Nodes with pathway None are never pruned. If either pathway has no summed member, nothing is pruned and the reason is recorded. The record carries the signed ΔΔG‡ keyed "<b>_vs_<a>" in rule order. ReactionNode gains pathway: str | None = None.
